# i18n PL/DE — rezygnacja z DeepL, tłumaczenia ręczne — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Usunąć cały automatyczny pipeline DeepL z etapu ① i18n; UI w pełni po niemiecku (słownik), treść produktów/kategorii tłumaczona ręcznie (panel) + jednorazowo przez Claude do kolumn `_de`.

**Architecture:** Bez zewnętrznej usługi tłumaczeń. UI = słownik w kodzie (`getDictionary`). Treść DB = kolumny `_de` (migracja 29) z odczytem fallback do PL; zapis ręczny przez panel (`saveProductDe`) + jednorazowy seed Claude. `needs_translation` = status „DE brakuje/nieaktualne".

**Tech Stack:** Next 16, Supabase (service role), vitest. Brak DeepL.

**Konwencje repo:** kod w `sklep-meblowy/`; komendy z `sklep-meblowy/` (`npm test`, `node_modules\.bin\tsc.cmd --noEmit -p tsconfig.json`, `npm run lint`, PowerShell); branch `feat/i18n-pl-de`; commity lokalne, BEZ pusha. `getLocale` z `@/app/_lib/i18n-server` (NIE z `i18n`). Klienckie komponenty: `useClientLocale`.

**Weryfikacja:** to refaktor (usuwanie + okablowanie), nie nowa czysta logika — bramka = `tsc` EXIT 0 + `lint` EXIT 0 + pełny `npm test` zielony (po usunięciu testów DeepL) + smoke runtime `/de`. Brak nowych testów jednostkowych.
